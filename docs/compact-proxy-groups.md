# 精简完整订阅分组

Clash / Mihomo 智能分流只展示三个主要入口：

- **普通代理**：默认故障回退，也能直接选择任一授权节点。
- **AI 代理**：按照已保存的 AI 选择方式，默认协议回退或手动固定节点；固定 Host 时，所有候选及回退仅限该 Host。不可用时拒绝连接，不跨 Host 或直连。
- **未分类流量**：默认普通代理，也能手动改为 DIRECT。

国内域名、国内 IP、局域网的 DIRECT 规则及 DNS 逻辑保持不变。AI 专用域名仍单独匹配，住宅代理仍由服务器只对 AI 流量应用。节点协议、凭据、CDN WebSocket 配置不变，CDN 域名不得固定 IP。

TCP 稳定、UDP 高速、RayLink 智能、故障回退、AI 稳定出口作为隐藏的内部策略保留。TCP 稳定继续支持已有 dialer-proxy 引用。旧主入口名称用隐藏别名保留；不引入额外健康检查。手动节点选择直接在主入口完成。

Mihomo 的 hidden 字段需要客户端界面适配。使用完整订阅更新，不能用仅节点订阅替代；旧客户端不支持隐藏时可能仍显示辅助组。共享健康检查版本的排序必须让自动策略排在节点前面，不能因 provider 排序而默认为单个节点。

验证边界：服务端公开订阅导出、实际 Mihomo 加载及控制器分组、真实代理请求和故障切换。检查两个 Mihomo 格式、手动模式、固定 Host 无权限、规则/DNS 引用、CDN、国内直连和默认/住宅出口隔离。客户端界面与手机体验未经实测不声称通过。
